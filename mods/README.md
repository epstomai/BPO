# 可选 MOD

启动器不自带、需要自己下载的 MOD。

| MOD | 作者 | 说明 | 下载 |
|-----|------|------|------|
| 移除开拓局广场长椅老人 | Arthur | 删除开拓局广场长椅上坐着的老人。只替换 Maps/cty/cty01/sublevel/cty01_EST。 | [remove-plaza-elder.zip](https://github.com/epstomai/BPO/raw/main/mods/remove-plaza-elder.zip) |

## 安装

1. 关闭启动器。
2. 把 zip 解压到 BPLocalRun.exe 旁边的 `data\mods` 文件夹里，解压后应为
   `data\mods\remove-plaza-elder\mod.json`（不要多套一层文件夹）。
3. 打开启动器，在 MOD 页里勾选启用（默认不启用），再开始游戏。

卸载：在 MOD 页取消勾选，再删掉 `data\mods\remove-plaza-elder` 文件夹。
